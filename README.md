🏥 Hospital Newborn Info System (Web App)
A simple and modern web application to register and manage newborn baby information for hospitals, clinics, or maternity wards.

✨ Features
Register Newborns – Capture key details like name, date of birth, gender, weight, and parent info.

View Records – Easily browse and manage registered baby information.

Tabbed Navigation – Seamless switching between registration and records.

Clean UI – Designed with Tailwind CSS for a responsive and user-friendly interface.

🌐 100% Web-Based – No installation needed. Just open in a browser.
